# FNV3P2 真实数据与脚本端到端验收（2026-10-14）

## 样本来源及边界

- 用户提供文件：`FNV3P2_2026_10_14T00_00_paired (1).csv`，放在 `/WNC数据使用示例/`，保持原样，不修改其字节内容。
- 根据文件名及第三方 `weathernext-download` 的模型列表，`FNV3P2` 是 **WeatherNext 2 Cyclones (r2)**，而非 WeatherNext 3 Cyclones（WNV3）。该模型标签未在数据内部单列，需要保留文件名/下载元数据。
- 起报时间 `2026-10-14 00:00 UTC`，四个气旋轨迹编号 `EP202026`、`EP212026`、`WP282026`、`WP962026`。
- 官方 Weather Lab 下载指南：https://developers.google.com/weathernext/guides/weatherlab
- 第三方下载工具模型表：https://pypi.org/project/weathernext-download/0.1.19/
- 这份文件没有显示独立的观测/实况标识列或模式版本列；不能仅凭文件名 `paired` 认定某行是观测值，更不能从这份文件单独验证预报误差。

## CSV Schema 与基本质量检查

- 文件最前面六行是 `#` 开头许可提示；第七行开始为真实 CSV 表头，23列，共 **4592条数据行**。原脚本 `read_csv` 不跳过注释，直接得到 Pandas C parser 字段数量冲突（第7行预期2列、实际23列），这是确定的兼容性缺陷。
- `sample` 值为整数0～49：**50个成员**，其中0是第0号成员而不是集合平均。
- 4条气旋信息：`EP202026` 763行（总体0～150h）；`EP212026` 1142行（总体0～234h）；`WP282026` 236行（总体0～54h）；`WP962026` 2451行（总体0～360h）。每个气旋均包含50个集合成员，但并非每个成员具有完整时效。以上为每个气旋在全部成员中的最大时效，不等于单个成员的最长时效。
- 按 `(track_id, sample, init_time, valid_time)` 检查重复组合：**0组**。
- 逐行核对 `lead_time_hours` 和 `valid_time-init_time`：**4592行全部一致**。
- `radius_34_knot_winds_se_km` 与 `radius_34_knot_winds_sw_km` 各有50个缺失，全部在 `EP212026` 的初始时效50个成员中。空值不能默认视为0。
- 原始风速字段 `maximum_sustained_wind_speed_knots`，最低气压 `minimum_sea_level_pressure_hpa`，风圈公里单位已在列名显式标识。

## 对旧脚本准确性的判定

| 项目 | 旧版 | 订正版 |
|---|---|---|
| 前置注释/许可信息 | 错误：读取直接抛 ParserError | `comment="#"` 跳过注释，保留原数据文件 |
| `lead_time_hours` | 未直接识别，只用起报与有效时刻算差 | 识别显式小时数，且两种方法交叉核对 |
| 多气旋/多成员混合 | 拒绝混合，正确 | 保留此保护 |
| `sample` 的集合含义 | 映射到 `member`，正确；但旧文档可能误导以为 mean | 明示 `sample=0` 非集合均值 |
| 数据发现 | `--inspect` 能看表头，但不能快速列表 | 新增 `--list-tracks` |
| 非 WNC 轨迹输入 | 可能静默输出空字段并成功退出 | 加入基本轨迹/强度字段校验 |
| 回归验收 | 9项纯合成测试 | 原9项 + 真实CSV 6项，共15项通过 |

## 实测结果（真实 CSV）

1. `--list-tracks`：4个气旋、成员0～49、各时效范围正确。
2. `--storm EP202026 --member 0 --at-lead-hours 24`：一条记录，`2026-10-15 00:00 UTC`、纬度 **19.77°**、经度 **-108.44°**、最大风速 **57.4 kt**、最低气压 **993.9 hPa**。
3. `--storm WP962026 --member 9 --max-lead-hours 48`：9条记录，48h窗口内风速峰值 **56.9 kt**、最低气压 **987.8 hPa**、最大可计算24小时风速变化 **+23.6 kt**，不满足30 kt快速增强数值阈值。
4. 不带 `--member` 直接筛 `EP202026` 会拒绝混合50个成员；时间差与显式小时数人工故意改成不一致时会报错，避免误用。
5. `python -m py_compile wnc_csv_demo.py` 通过；`python -m unittest -v test_wnc_csv_demo.py test_wnc_csv_real.py` **15项通过**。

## 后续验证与限制

- 已验证的是 **CSV的正确读取、字段语义映射、成员筛选、预报时效、风速及气压计算、导出**；并未用后验实况对模型预报精度做科学验证。
- 未验证其他产品（特别是独立集合均值 CSV、OPER、WNV3、ATCF、不同年份）的全部兼容性。
- 代码不会自动估计集合平均路径、集合强度分布或快速增强概率。要做集合概率分析，需要新建明确按成员逐条配对、指定有效成员分母的聚合程序。
- 来源处写的模型名称是基于文件名和工具文档的对应关系，不是从 CSV 内嵌的 model 列直接提取。保留原数据和相关许可文字。
