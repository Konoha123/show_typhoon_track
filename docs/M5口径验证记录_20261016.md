## 结构事实

- 两文件 23 列表头完全一致（与 FNV3P2 相同），6 行 `#` 许可头；现有解析管线（`--inspect`/`--list-tracks`）无损读入。
- **WNV3 为 64 成员**（sample 0–63）；FNV3P2 为 50 成员——成员数不可硬编码。
- `init_time` 格式在不同导出间不统一：WNV3 为 `YYYY-MM-DD HH:MM:SS`，FNV3P2 为 `YYYY-MM-DD`（仅日期）；`normalize` 的 `pd.to_datetime(utc=True)` 两者均可解析（仅日期 → 00:00 UTC）。
- 经度两文件均为 −180–180° 约定（WNV3 范围 −164.51～172.86），无需 0–360 转换。
- 数据质量（ensemble 文件）：`(track_id, sample, init_time, valid_time)` 重复 0 组；`lead_time_hours` 与 `valid_time−init_time` 不一致 0 行；空值仅 `radius_34_knot_winds_ne/nw_km` 各 64 处。
- 逐 (track, lead) 在场成员数：WP292026 自 lead 216 起递减（62→57→44→35→30→20→14→9→6→4→3→1→1 至 lead 288），其余三个气旋基本满员——成员消散导致分母随时效衰减。

### 关键排除过程（防止结论误用）

1. **算术平均 lat/lon 是错误口径**：WP292026 尾部（lead 186–246，成员 64→20）与算术平均偏差随时效增大（最大 ~1° 纬度 / ~1.8° 经度），曾误判"位置不可复现"；改用球面矢量平均后 94/94 吻合。
2. **消散成员沿用最后位置的 persistence 口径不成立**：尾部偏差反而增大（lead 246 达 +3°）。
3. **中位数口径不成立**：仅 13–14/94 点吻合。
4. 强度量（风速/气压/RMW）在尾部同样精确吻合"在场成员平均"，确认尾部处理为方案 b。

## 采纳的系统口径（M5 实现依据）

| 项 | 决策 |
|---|---|
| 平均强度 | 自算：逐时次在场成员风速/气压算术平均（本记录已验证与官方产品一致） |
| 平均位置 | 自算：球面矢量平均（`core.geo.spherical_mean`，本记录已验证一致） |
| 尾部 | 方案 b：仅统计在场成员，逐时次暴露分母 n；消散数 = 成员总数 − 在场数 |
| 低分母 | n < 30% × 成员总数 → 前端虚线 + 标注（不删数据、不截断） |
| 概率半径 | 离球面均值中心最近 p% 成员的最小 haversine 半径；p ∈ {40,50,60,70,80,90,100}%，默认 100% |
| mean 文件接入 | 不做 `sample=-1` 特判，按普通单成员预报导入（统计一律自算） |
| 堆叠图层级 | 自底向上：已消散→TD→TS→H1→H2→H3→H4→H5（强度单调向上；消散不与 H5 相邻） |
