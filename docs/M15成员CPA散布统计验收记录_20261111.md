| 项 | 口径 |

| 方位分箱 | 地点→CPA 位置方位角按 compass_8 分 8 扇区（22.5°+k·45° 分界归顺时针下一方位）；格为 8 扇区×4 环带增量 (prev, r] |
| 原点区 | CPA < 30 km（正面穿越）不入扇区格、计入 ≤100 档与分母，散点钉圆心 |
| 环外 | CPA > 800 km 不入任何档/格，图下注记，明细仍含 |
| 与 mean 口径关系 | mean 最近接近仍走 M11a 截断口径不变；成员 CPA 走全程时次口径（成员细线不截断的同侧口径），两口径并存有意为之 |
| 展示 | 影响概率卡片：分档 4 数值行（数量+比例）+ 混合玫瑰图（散点层一成员一点·真实方位角·带内分段线性径向映射 + 分箱层 8×4 格计数）；等宽序数环带 + 环外注记；自绘 SVG 无新依赖 |
| 单源 | 档位与原点阈值 `core/impact.py` 常量（CLOSEST_DISTANCE_RADII / CPA_ORIGIN_RADIUS_KM），随 STATS_CONFIG 注入页面；参考圆绘制改消费注入值（原「仅视觉参考，不参与判定」声明废止），前端硬编码删除 |

## 核验结论

### 1. core 独立复算（tests/test_core_impact.py::test_real_member_cpa_independent_recomputation）

- 目标点：EP202026 lead 0 自算均值位置东南 350 km（确定性构造）；
- 独立实现：测试内自写 haversine / 初始方位角 / 8 方位扇区公式（不复用 core.geo，
  规避同源盲区）+ pandas 逐成员最小距离 → 分档、扇区格、原点、环外全量重算对照；
- 结果：64 成员明细距离逐一 `approx(abs=1e-6)` 一致；分档/格/原点/环外计数完全一致；
  守恒式（扇区格 + 原点 + 环外 = 有明细成员数）成立。**通过**。

- 扇区格分布：S 3+5、SW 5+26+8、W 4+13（自内向外按 100/200/400 档）——通过侧
  **全部落在 S/SW/W**，即全体成员从目标以北/以西通过（典型东太平洋西行风暴沿

## 发现的问题与修复

1. **成员 CPA 累积必须置于风圈「已全命中跳过」优化之前**（core/impact.py 主循环）：
   该 continue 只保证已全命中的成员无需再看风圈，不豁免 CPA 的逐行累积——若放在
   之后，等价于把命中成员的 CPA 截断到首命中时次，静默错误。已按正确顺序实现并以
   「多时次命中成员」用例覆盖。
2. **E2E 那霸远点用例 `text.count("0.0%")` 由 4 变 8**：M15 分档 4 行在远点目标下
   同为 0.0%（全部成员环外），属预期行为变化，断言已随口径更新（4→8）并加注记断言。
3. ruff B905（zip 无 strict）/ B007（循环变量未用）等测试代码小项已修；正式源码零告警基线保持。
4. 实现过程中曾误引入占位残片（`_member_cpa_stats` 首版含 `NotImplementedError` 与
   无定义引用），已在同轮内以干净实现覆盖；L0/L1 全量验证保证无残留。

## M15-R1 使用反馈修正（2026-11-11）：玫瑰图全线性 + 悬停 readout

> 用户反馈两项：径向分段线性各带压缩比不一致（1 : 0.7 : 0.35 : 0.175）致距离感
> 失真；图内常驻格计数只显数量没算比例、且 SVG 绘制顺序计数先于散点、密集时必被
> 点盖住。方案经逐项确认（readout 默认态/纯重叠/空格文案三项微确认后定稿）。

### 口径定稿

| 项 | 定稿 |
|---|---|
| 径向映射 | **全线性** r = d/800 × rOut；环导轨画在真实比例位置（100/200/400/800 → 半径 12.5%/25%/50%/100%）；等宽序数环带与分段线性废止 |
| 原点区 | 退化为**纯统计箱**：无钉死圆心、无微环散开，<30 km 自然落位（≤5 px 圆心簇）、近中心多点自然纯重叠（计数悬停可查） |
| 图面 | 纯几何（真实比例环 + 扇区导轨 + 扇区标签 + 散点）；图内常驻格计数文本与图下底注废止；网格保留为参考线 |
| 悬停 | mousemove 数学分箱（光标极坐标 → 扇区×环带，分界同 core.compass_8；33 命中域零额外 DOM）+ 当前格淡色 wedge 高亮 + readout 条（复刻强度分布图 `.readout` 形态：图区右上角、pointer-events none） |
| readout 文案 | 格 `{扇区} ({lo}–{hi}] km \| n (p%)`；空格 `- (0.0%)`；原点 `原点(<30 km) \| n (p%)`；默认态常显 `成员 N · 原点 n (p%) · 环外 n (p%)`（环外图外不可悬停故常显）；格比例分母 = 成员总数（与分档行一致） |
| 其余 | 分档数值行保留不动；后端零改动（载荷已齐备）；?v=m15r1 |

### 问题处置

1. 悬停首测失败：影响卡片 `max-height: 360px` 可滚动，玫瑰图未滚入视口时
   `bounding_box` 坐标落在卡片外（mouse.move 命中卡片边缘而非 svg）——测试补
   `scroll_into_view_if_needed()` 后通过（应用代码无缺陷）。
2. 那霸用例原 `count("0.0%") == 8` 在 readout 默认态（`原点 0 (0.0%)`、`环外 2 (100.0%)`
   含子串）下必然失真——改为按行/readout 结构化断言，消除全文计数歧义。
3. **M15-R2（用户反馈疑似 bug，坐实）：悬停 wedge 高亮方位 off-by-one 扇区**——
   根因：wedge 起始角 `a0 = 22.5 + sectorIdx·45` 把扇区的顺时针**终止边界**当成了
   起始边界（扇区 k 角域实为 [22.5+(k−1)·45, 22.5+k·45)），每个楔形向顺时针偏移
   一格（悬停 N 高亮 NE 角域）；而 readout 文案与 data-hover-bin 走 sectorIdx 直映
   均正确——与用户报告「高亮区域方位错、其余两者正确」一致。修复：a0 改
   `22.5 + (sectorIdx−1)·45`（N 扇区 −22.5°≡337.5° 跨 0°，cpaPolar 周期性天然处理）；
   回归锁定：E2E 悬停 N (100–200] 格断言 wedge 首点 = polar(337.5°, 200/800×132)
   ≈ (147.4, 129.5)（红→绿实证：旧代码该点为 172.6@22.5°，偏移恰 45°；N 跨 0°
   同时锁死 wrap 场景）；?v=m15r2。E2E 全量两轮间曾现一次 `Page.goto` 30s 超时
   （瓦片网络抖动，沿 M8b/M9a/M10b 先例），单用例复跑与整轮重跑均 43 项全绿。

## M15-R3 使用反馈迭代（2026-11-11）：CPA 散点按强度着色

> 用户提议：CPA 散点由统一灰色改按强度着色（其它逻辑不变）。口径经逐项确认：
> 强度取「成员在 CPA 时次的风速」（非终生峰值——语义为「接近时多强」，数据即在
> CPA 候选行手边、零额外关联）；CPA 图旁不加图例小注（强度色阶已由地图图例解释）。

### 口径定稿

| 项 | 定稿 |
|---|---|
| 强度口径 | CPA 时次（被选中的距离最小行）的 wind 值；非终生峰值、非峰值/末/它行风速 |
| 色阶 | 复用 `windColor`（WIND_SCALE 单源注入，与地图轨迹点/图例/强度分布同源）：70 kt→H1 `#ffd166`、42/36 kt→TS `#66c2a5` 等 |
