# M15 成员 CPA 散布统计验收记录（2026-11-11）

## 需求与口径回顾

目标地点的影响统计新增**成员级 CPA（最近接近点）**维度（用户逐项确认）：

| 项 | 口径 |
|---|---|
| 成员 CPA | 逐成员存在期全部输出行（消散=行终止，无哨兵行）中心到目标 haversine 距离最小值；一成员一点；并列等距取最早时效（lead 缺失时次仍可参选，仅并列排序视为最晚） |
| 距离分档 | 累积「≤ r km」含等号，r=100/200/400/800（与参考圆档位同源）；分母=成员总数（M5 n_total 同口径）；无有效坐标成员留分母 |
| 方位分箱 | 地点→CPA 位置方位角按 compass_8 分 8 扇区（22.5°+k·45° 分界归顺时针下一方位）；格为 8 扇区×4 环带增量 (prev, r] |
| 原点区 | CPA < 30 km（正面穿越）不入扇区格、计入 ≤100 档与分母，散点钉圆心 |
| 环外 | CPA > 800 km 不入任何档/格，图下注记，明细仍含 |
| 与 mean 口径关系 | mean 最近接近仍走 M11a 截断口径不变；成员 CPA 走全程时次口径（成员细线不截断的同侧口径），两口径并存有意为之 |
| 展示 | 影响概率卡片：分档 4 数值行（数量+比例）+ 混合玫瑰图（散点层一成员一点·真实方位角·带内分段线性径向映射 + 分箱层 8×4 格计数）；等宽序数环带 + 环外注记；自绘 SVG 无新依赖 |
| 单源 | 档位与原点阈值 `core/impact.py` 常量（CLOSEST_DISTANCE_RADII / CPA_ORIGIN_RADIUS_KM），随 STATS_CONFIG 注入页面；参考圆绘制改消费注入值（原「仅视觉参考，不参与判定」声明废止），前端硬编码删除 |

## 核验结论

### 1. core 独立复算（tests/test_core_impact.py::test_real_member_cpa_independent_recomputation）

- 目标点：EP202026 lead 0 自算均值位置东南 350 km（确定性构造）；
- 独立实现：测试内自写 haversine / 初始方位角 / 8 方位扇区公式（不复用 core.geo，
  规避同源盲区）+ pandas 逐成员最小距离 → 分档、扇区格、原点、环外全量重算对照；
- 结果：64 成员明细距离逐一 `approx(abs=1e-6)` 一致；分档/格/原点/环外计数完全一致；
  守恒式（扇区格 + 原点 + 环外 = 有明细成员数）成立。**通过**。

### 2. 真实数据抽核数值（EP212026 @ 19.05, -104.32，与 M6 抽核同点）

| 档位 | 命中/总数 | 比例 |

| ≤200 km | 56/64 | 87.5% |
| ≤400 km | 64/64 | 100% |

- 原点区 0、环外 0；最近成员 `19`：42.76 km / lead 54 h / 方位 286.7°（W）；
  最远成员 `18`：273.3 km（SW）。
- 扇区格分布：S 3+5、SW 5+26+8、W 4+13（自内向外按 100/200/400 档）——通过侧
  **全部落在 S/SW/W**，即全体成员从目标以北/以西通过（典型东太平洋西行风暴沿
  墨西哥海岸平行移动的形态），与 mean 最近接近（lead 54 h / 140 km / SSW）自洽。
  气象读法成立：该点处于风暴行进方向左侧（弱侧）。

## 发现的问题与修复

1. **成员 CPA 累积必须置于风圈「已全命中跳过」优化之前**（core/impact.py 主循环）：
   该 continue 只保证已全命中的成员无需再看风圈，不豁免 CPA 的逐行累积——若放在
   之后，等价于把命中成员的 CPA 截断到首命中时次，静默错误。已按正确顺序实现并以
   「多时次命中成员」用例覆盖。
2. **E2E 那霸远点用例 `text.count("0.0%")` 由 4 变 8**：M15 分档 4 行在远点目标下
   同为 0.0%（全部成员环外），属预期行为变化，断言已随口径更新（4→8）并加注记断言。
3. ruff B905（zip 无 strict）/ B007（循环变量未用）等测试代码小项已修；正式源码零告警基线保持。
4. 实现过程中曾误引入占位残片（`_member_cpa_stats` 首版含 `NotImplementedError` 与
   无定义引用），已在同轮内以干净实现覆盖；L0/L1 全量验证保证无残留。
