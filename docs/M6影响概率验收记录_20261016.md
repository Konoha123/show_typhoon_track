## 发现的问题与处置

1. `summary.py` pyright 既有报错（pandas 桩版本漂移致 `nunique` 返回联合类型）→ 随 M6a 最小收口
   （`cast("int", …)`，无行为变化），恢复全仓零告警基线；
2. E2E 等待 `[data-target-marker]` 超时：divIcon 容器为 0×0（CSS 定位惯例），Playwright 默认等"可见"
   → 改 `state="attached"`（与既有 mean-dot 锚点同处理）；
3. 预存地点经度回显出现 `127.68089999999995`：`toSignedLon` 模运算浮点尾差 → `setTarget` 对已在
   [−180,180] 内的经度原值保留，越界才归一；
4. 测试预期修正（非产品缺陷）：球面正反方位角之差一般不恰为 180°（子午线收敛）、大圆方位对
   "正西/东北"有 0.1°–0.7° 偏差、EP202026 全程无 64 kt 风圈（改按数据实况动态选气旋）。
