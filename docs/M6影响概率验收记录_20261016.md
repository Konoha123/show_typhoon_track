## M11a 章节：最近接近截断口径修复（2026-10-28）

> 使用反馈：影响概率卡片「最近接近（mean 口径）」可采纳低分母尾段（仅剩少数消散残留
> 成员）的均值中心，与前端自 M5d-R1 起止于首个低分母时次的 mean 线口径矛盾。
> 本节为 M11a 修复记录（里程碑总口径见 `docs/里程碑基线.md`「M11」）。

### 现象与最小复现

4 成员合成集合：0/24/48h 全员在场（mean 位置 10N/130E），72h 起仅成员 0 存活
（n_present=1/4=25% < 30% → 低分母）且尾段中心移至 15N/130E；目标取 (15, 130)。
修复前 `impact_profile(...).closest` 报 **72h / 0.0 km**（该时次均值中心恰在目标上，
但图上 mean 线已截断、根本不绘制该段）；修复后回退到截断内最近时次 **lead 0 /
≈556 km**（与 mean 线可见口径一致）。已固化为回归测试
`tests/test_core_impact.py::test_impact_profile_closest_truncated_before_low_denominator_tail`。

### 根因

- 前端 mean 线（M5d-R1 起）与时效滑块域（M5d-R11 起）均截断于首个低分母时次；
  而后端 `core/impact.py` 的 `_closest_approach` 遍历 `ensemble_profile` 全部时次，
  尾段均值中心仅由少数存活成员决定、不具集合代表性，却可能恰最贴近目标，
  把「最近接近」整体拽入截断区。

### 修复口径（用户确认）

1. 最近接近只在截断内时次选取（规范口径：完整时次序列上止于首个
   `low_denominator=True` 之前）；core 新增 `low_denominator_cut_lead`（原语）与
   `effective_lead_profiles`（切片）纯函数，为规则唯一实现（M11b 前端经
   ensemble-stats 字段消费，届时消除前端自算与两处实现的口径分叉）；
2. 三级风圈概率与核心强风区命中维持全时次口径不动（成员级判定，消散成员自然不命中）；
3. 极端全低分母 → closest=None（缺失保持缺失，不退回首时次），以原因码区分：
   `no_mean_position`（全程无有效均值位置）/ `truncated_empty`（截断内无有效时次）；
   api 层 `ImpactStatsResponse.closest_note` 映射中文文案（`CLOSEST_NOTE_TEXTS` 单源），
   前端卡片优先展示 note（`?v=m11a`）；
4. 单成员轨迹 `low_denominator` 恒为 False，不截断、行为不变（回归锁定）。

### 真实数据影响评估（修复前只读复算）

- EP212026（曼萨尼约抽核点，M6c 锁定值 54h/140.09km/SSW）：首个低分母时次 144h
  （n_present 序列 64→…→11），closest 落在截断内，**既有断言不变**；
- EP202026：首个低分母 54h；SH922026：114h——`test_real_wnv3_pair`/`test_core_impact`
  真实用例（lead0 均值中心点、远点 >1000km）均稳健，全量回跑通过。

  core.impact 4（尾段回退回归、极端全低分母 None+原因、位置仅在尾段 truncated_empty、
  单成员不截断）+ api 2（truncated_empty / no_mean_position 文案，no_mean_position 用
  双气旋数据集规避上传端 lat 列全缺失校验）+ OpenAPI 含 `closest_note`；
