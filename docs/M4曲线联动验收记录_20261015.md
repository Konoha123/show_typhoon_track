# M4 曲线联动验收记录（2026-10-15）

## 验收范围

M4 里程碑：强度曲线联动——主区上下分割（地图 65% / 曲线 35%），曲线与地图**同源数据、同配色、同滑块截断**，双向联动。后端零改动（复用 M2 tracks 接口）。

- 单成员：风速 kt（左轴）+ 气压 hPa（右轴，虚线）双轴曲线；曲线 hover → 地图对应点放大高亮（readout 显示时效/风速/气压）；点击 → 地图 panTo + 打开 Popup；地图点位 hover → 曲线游标定位（`valToPos + bbox.left` → `setCursor`）。
- 全部成员：每成员风速细线（`memberColor` 与地图意面图同一调色板、同一 groupBy 顺序）；曲线 hover 最近线自动聚焦（`cursor.prox + focus.alpha`，其余变淡）并联动地图该成员折线加粗（`setSeries` hook）；地图折线 mouseover/mouseout → 曲线聚焦/取消（`setSeries` API）。
- 数据纪律：x 轴档位 = 实际存在的 `lead_h`（不插值）；缺失保持 null（`spanGaps: false`，不跨缺口连线）；不画集合均值/包络；曲线随滑块与地图同截断于 `leadCut`。
- 窗口 resize 仅重建曲线图（150 ms 防抖）。
