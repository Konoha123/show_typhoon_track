# 瓦片数据源确认记录（2026-10-15）

## 选型结论

M3 地图底图采用 **ESRI World Imagery**（`server.arcgisonline.com`，AWS 托管），为最普遍且无需密钥的
AWS 瓦片服务；URL 模板与归因写入根目录 `config.toml`，前端经后端注入，代码中不硬编码。
多瓦片源切换属 M5+ 范围。

## 官方服务确认（2026-10-15 实时取自服务端点）

- 服务元数据：`https://server.arcgisonline.com/arcgis/rest/services/World_Imagery/MapServer?f=pjson`
  （HTTP 200，`currentVersion: 11.3`）
- 关键参数（取自响应 `tileInfo`）：瓦片 256×256、JPEG（压缩质量 90）、Web Mercator（EPSG:3857）、
  `singleFusedMapCache: true`、LOD level 0–23。
- 瓦片 URL 模式：ArcGIS REST 缓存服务标准模式
  `https://server.arcgisonline.com/arcgis/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}`
  （注意顺序为 z/y/x；Leaflet 按占位符名替换，模板字符串保持该顺序即可）。
- 归属声明（服务 `copyrightText` 原文）：
  `Source: Esri, Vantor, Earthstar Geographics, and the GIS User Community`
- 官方说明页（服务自述引用）：https://goto.arcgisonline.com/maps/World_Imagery

## 本机可达性实测

| 项目 | 结果 |
|---|---|
| 服务元数据 | HTTP 200，application/json |
| 样例瓦片 `tile/3/2/4` | HTTP 200，image/jpeg，256×256，约 2.8 s（经代理） |

## 配置落地

- `config.toml`（根目录）：`[tiles] url_template / attribution / max_zoom`（默认 max_zoom=18）。
- 后端 `typhoon_track/api/app.py` 读取并注入页面模板；模板/占位符缺失即启动报错，防止静默错配。
