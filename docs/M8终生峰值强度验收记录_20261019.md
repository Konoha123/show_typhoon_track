# M8 终生峰值强度验收记录（2026-10-19）

## 需求与口径确认

- 需求（用户，2026-10-18）：基于导入数据与选中气旋，计算每个集合成员预测的峰值强度与峰值气压，再对全体成员计算这两个指标的中位数与平均数。
- 确认过程：先做可行性分析（字段/分层挂接点/口径合规），随后 7 个开放问题逐项由用户确认；其中"消散按 ±∞ 处理"与数据模型存在矛盾（消散 = 行提前终止，无显式标志，成员存在时次仍有真实风压），经第二轮澄清后采用**有限峰值参与统计**方案。
- 最终口径（全文登记于 `docs/里程碑基线.md`「M8」）：
  1. 终生最大风速 = 成员全部行 `wind` 的 max；终生最低气压 = `pressure` 的 min；独立取极值、各报出现时效，并列取最早（沿 M6 最近接近先例）；
  2. 统计窗口 = 整条预报轨迹，不受时效滑块影响；
  3. 聚合 = 上中位值（升序第 floor(n/2)+1 个，偶数成员取较大者）+ 算术平均；
  4. 分母 = 出现过的成员一律以有限峰值参与；指标全缺成员为哨兵（该指标中剔除、列表显"-"），n_wind/n_pressure 逐指标暴露；
  5. mean 产品文件不做 `sample=-1` 特判（沿 M5 决策，合并上传会作为一个成员混入分母——仅文档说明）；observation 数据集 400 拒绝 + 前端无统计内容；
  6. 呈现 = 最右侧第四栏（默认隐藏、右缘按钮展开），4 聚合数 + 每成员峰值列表；
  7. 单位 kt / hPa 原样输出不换算。
- 命名依据：**lifetime peak intensity（终生峰值强度）** 为热带气旋气候学标准术语（Zeng et al. 2007 MWR、Mei et al. 2015、Kim et al. 2022 等，亦作 lifetime maximum intensity），与 M5「逐时次强度分布」（时效切片）明确区分。

## 真实数据核验结论

- **core 独立复算**（`tests/test_core_peak.py`，四气旋逐成员）：64 成员 × 4 气旋的峰值风速/最低气压及其最早出现时效与独立 pandas 复算完全一致；聚合（上中位/平均）一致。
- **锁定值**（2026-10-16 首算，三层一致）：

| 气旋 | 风速上中位/平均（kt） | 气压上中位/平均（hPa） | 最强成员 |
|---|---|---|---|
| EP202026 | 45.0 / 45.359375 | 999.0 / 998.6515625 | 25：51.5@6h / 999.0@**0**h |
| EP212026 | 115.8 / 115.1734375 | 949.7 / 949.4453125 | 36：132.3@36h / 934.0@36h |
| SH922026 | 82.0 / 82.0390625 | 971.7 / 970.775 | 15：110.5@42h / 949.3@42h |
| WP292026 | 157.6 / 156.5546875 | 902.2 / 902.259375 | 41：168.6@78h / 891.4@78h |

- **风压不同步的真实例证**：EP202026 成员 25 的风速峰在 6 h、气压谷在 0 h——"各自独立取极值"口径的直接实证（若绑定峰值时刻取气压，会得到 6 h 的值）；已固化为测试。
- WP292026 的 63/64 成员行提前终止（消散），全部以有限峰值参与统计（专项合成测试锁定：错误地按哨兵剔除会使中位数从 50 变 80）。
- api 集成锁定 WP292026 聚合与成员 41 行；浏览器验收锚点（data-peak-wind-median 等）与之一致。

## 问题与处置

1. **pyright 环境解析**：`python -m pyright` 未自动选中 conda 环境（reportMissingImports），改用 `--pythonpath <env python>` 显式指定；后续应优先在激活环境内运行。
2. **pandas 桩漂移**（沿 M6a 先例，仅 cast 无行为变化）：core `_extreme_with_earliest_lead` 的 `min(leads)` 需显式收窄 `float | None` → 循环内 `is not None` 判定；测试独立复算的 `float(Series.max())` 需 `cast("float", …)`。
3. **Windows GBK 编码**：`deptry`/`lint-imports` 读取含中文的 requirements / .importlinter 报 UnicodeDecodeError，需 `PYTHONUTF8=1` 运行（环境层问题，非代码缺陷）。
4. **E2E 瓦片网络抖动**：M8b 全量回跑时 1 项 `Page.goto`（等 load 事件，含外部瓦片）超时，与本次改动无关（未触前端）；单用例复跑通过后整轮重跑 231 全绿方认定通过。
5. **测试断言自纠**：开发中将 3 元素上中位误算为 1004（应为正中 1002），测试失败暴露后修正断言——上中位口径在奇数成员时即正中。
6. **提交信息转义**：PowerShell 下 `\"` 拆断 git 参数，提交信息内引号改用全角「」。
7. **浏览器验收脚本时序**：切气旋后原等待条件被旧气旋满足（EP202026 与 WP292026 同为 64 成员），改用时效滑块 max 档位变化（26→49 档）作为切换完成信号后稳定。
8. 一次性验收脚本与临时 store 均置于系统临时目录，不入仓库。
